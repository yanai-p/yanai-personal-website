# ינאי פרסונל

## מסירה עדכנית — 17 בנובמבר 2026

האתר סטטי. קובצי האתר להגשה נמצאים ב־`dist/`, כולל המדיה, הגופנים, קובצי הסגנון והסקריפטים. אין צורך ב־Node או בשרת API לצורך הצגת האתר.

## פריסה וגרסאות

כל push ל־`main` מריץ בדיקות, מפרסם את `dist/` ב־GitHub Pages, בודק שהאתר החי מגיש את הגרסה החדשה ומשחרר Release בשם `vX.Y.Z` עם קובץ zip של האתר. ה־CI רץ רק על ה־runner במחשב העבודה (WSL `ci-runner`, תווית `work-pc`). הגרסה החיה מופיעה ב־`/version.json`. פירוט ב־[README הראשי](../README.md).

## הפעלה מקומית

משורש המאגר: `docker compose up -d --wait`. השירות מגיש את `yanai-site/dist` באמצעות Nginx בפורט `4173`, עם מיפוי לקריאה בלבד. שינויים זמינים ברענון בלי בנייה מחדש. מצב: `docker compose ps`. עצירה: `docker compose down`.

ללא Docker, ורק כשהפורט פנוי: מתוך `yanai-site`, הריצו `python -m http.server 4173 --bind 127.0.0.1 --directory dist`.

כתובת: http://localhost:4173/

## שפות ותוכן

עברית היא ברירת המחדל וב־RTL. השפות הנוספות: תאילנדית, הינדי, סינהלית, סינית מפושטת, רומנית, אוזבקית בכתב לטיני ואנגלית. בחירה ישירה: `?lang=en` וכדומה. בורר השפה שומר את פרטי הטופס.

קטלוגים: `translations/*.json`. לאחר עריכה: `npm run build:locales`. יש 316 ערכים בכל שפה. פירוט ומגבלות הבדיקה הלשונית ב־`translations/README.md`. התרגומים עברו סקירה טכנית ולשונית בסיוע AI; אין כאן אישור של מגיהים דוברי שפת אם.

לא נוספו לקוחות, נתוני הצלחה, המלצות או זמני אספקה מומצאים. מדיה ומקורות מתועדים ב־`ASSETS.md`.

## מדיה, תנועה ונגישות

- ה־Hero משתמש בסרטוני אתרי העבודה שסופקו על ידי הלקוח: `yanai-hero-sites-60fps-web.mp4` בדסקטופ (9.47MB) ו־`yanai-hero-sites-60fps-web-mobile.mp4` במסכים צרים (3.21MB), ותמונת גיבוי מקומית.
- הסרטון מושתק ומתנגן אוטומטית כשהדפדפן מאפשר. הוא נעצר מחוץ למסך או בלשונית מוסתרת; העדפת הפחתת תנועה/חיסכון בנתונים משאירה תמונת גיבוי. אין בקרת עצירה או פס התקדמות בתוך ה־Hero, בהתאם לעיצוב המאושר; בקרת הפחתת תנועה נמצאת בפוטר.
- תמונות המקצועות נטענות ברקע בעדיפות נמוכה ומפוענחות לפני המעבר. חיסכון בנתונים מבטל הורדה ספקולטיבית.
- אנימציית הבנייה עוקבת אחר גלילה רגילה. במובייל אין נעילת גלילה. ניווט דסקטופ נשאר פתוח; במובייל הוא מצטמצם ללוגו בגלילה מטה ונפתח בגלילה מעלה.
- האתר כולל שמות נגישים, תוויות, מצבי פוקוס, תפריטים וחלוניות עם מקלדת, SVG דקורטיביים וטקסט חלופי לתמונות. הבדיקות אינן מהוות הסמכת נגישות.

## בדיקות ומסירה לענן

`npm test` מריץ בדיקות טופס, שפות, ניווט, שלבי בנייה, תמונות ווידאו. `npm run build:locales` בודק שלמות והתאמה בין הקטלוגים.

לפריסה יש להגיש את תוכן `dist/` בשורש האתר, בלי `node_modules`, בדיקות, צילומי QA או תיקיית המקור של המדיה. אין כתובות localhost או מנהרת התצוגה המקדימה בתוך קובצי האתר. הכתובות פנימיות יחסיות; קישורי טלפון, מייל ו־WhatsApp מפורשים.

בשרת הסופי יש לשמר סוגי MIME תקינים, תמיכה ב־Range לווידאו ודחיסת טקסט. `preview-nginx.conf` הוא דוגמה קיימת. יש לבדוק אחרי הפריסה HTTPS, טעינת מדיה, שפות והעברה ל־WhatsApp בדומיין הסופי; תנאי שרת הענן ורשת סלולרית אמיתית לא נבדקו בסביבה המקומית.
